# 通信协议规范

服务端采用基于 HTTP 的二进制流式 RPC 协议，底层使用 Protocol Buffer 的 Varint 变长整型及消息格式进行序列化。

---

## 接口路径

```http
POST /
```

---

## 请求格式 (Request)

请求体为二进制数据（`Uint8Array`），支持在单个 HTTP 请求中并发批量打包不同业务模块（`mod`）的多个调用。

每个请求分块（Request Chunk）结构如下：

```text
+---------------------+---------------+--------------------+------------------------------+
|     Mod (bytes)     |  ID (varint)  |  Length (varint)   |       Payload (bytes)        |
+---------------------+---------------+--------------------+------------------------------+
| utf8(mod) + 0x00    | uint32(id)    | uint32(len)        | Call Protobuf Binary (len B) |
+---------------------+---------------+--------------------+------------------------------+
```

### 字段说明

| 字段        | 编码方式          | 说明                                                                  |
| :---------- | :---------------- | :-------------------------------------------------------------------- |
| **Mod**     | `bytes (\0 结尾)` | 目标业务模块标识（以 `\0` / `0x00` 结束的 UTF-8 字符串，如 `auth\0`） |
| **ID**      | `varint (uint32)` | 客户端生成的调用自增唯一标识                                          |
| **Length**  | `varint (uint32)` | 当前调用的 Protobuf 二进制负载字节长度                                |
| **Payload** | `bytes`           | 对应模块 `Call` 的 Protobuf 编码数据（包含方法编号 Tag 与参数）       |

---

## 响应格式 (Response)

服务端以二进制流（`ReadableStream`）形式分块推送响应。每个调用处理完成后独立产出响应分块，无需等待其他并发调用。

### 1. 包含数据体的响应分块（`Status <= ERR`，即 `OK` 或 `ERR`）

```text
+---------------+-----------------+------------------+--------------------+
|  ID (varint)  | Status (varint) |  Length (varint) |    Body (bytes)    |
+---------------+-----------------+------------------+--------------------+
| uint32(id)    | uint32(status)  | uint32(len)      | Result / Error Str |
+---------------+-----------------+------------------+--------------------+
```

### 2. 无数据体的响应分块（`Status > ERR`，如 `CAPTCHA`、`NO_ORG`）

```text
+---------------+-----------------+
|  ID (varint)  | Status (varint) |
+---------------+-----------------+
| uint32(id)    | uint32(status)  |
+---------------+-----------------+
```

---

## 状态码定义 (Status)

| 状态码 | 常量名    | 说明                 | 结构与 Body 内容                                         |
| :----: | :-------- | :------------------- | :------------------------------------------------------- |
|  `0`   | `OK`      | 执行成功             | 包含 `Length` 与 `Body`（Protobuf 序列化数据）           |
|  `1`   | `ERR`     | 服务端内部执行错误   | 包含 `Length` 与 `Body`（`err.toString()` UTF-8 字符串） |
|  `2`   | `CAPTCHA` | 需要人机验证码校验   | 无 `Length` 与 `Body`（仅返回 `ID` 与 `Status`）         |
|  `3`   | `NO_ORG`  | 请求未匹配到有效机构 | 无 `Length` 与 `Body`（仅返回 `ID` 与 `Status`）         |
