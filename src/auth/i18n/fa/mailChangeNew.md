تغییر ایمیل: `${=it.from}` → `${=it.to}` (کد تأیید ایمیل جدید: `${=it.code}` )

شما برای تغییر آدرس ایمیل حساب خود درخواست می دهید: `${=it.from}` → `${=it.to}`

اگر این عملیات خودتان است، کد تأیید ایمیل جدید این است:

`${=it.token_str}`

کد تایید به مدت بیست و چهار ساعت معتبر است.

اگر درخواستی برای تغییر آدرس ایمیل خود نکرده اید، لطفاً این ایمیل را نادیده بگیرید.
